# Journaux techniques — Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, then one whole-change review. Steps use checkbox syntax.

**Goal:** Add an operational Journaux tab matching the supplied console screenshots.

**Architecture:** Reuse React, FastAPI, authenticated cookie sessions and the existing persistent SQLite volume. Store bounded, redacted diagnostics separately from the decision history. Instrument communication boundaries with safe summaries; never store raw credentials, OAuth responses or full protocol payloads.

**Tech Stack:** Existing Python/SQLite/React/TypeScript/Playwright; no new dependencies.

**Spec:** User screenshots and request, 2026-10-30. Builder choices: latest 500 lines, incremental polling every 3 seconds while visible, pause, minimum severity, multi-area filtering, case-insensitive search, older-page loading, filtered text download. Retain at most 10,000 entries and seven days. WARN/ERROR/FATAL colors, keyboard/touch accessible controls, light/dark themes, iPhone widths down to 320px. Persistent collection is independent of the viewing pause.

## Global constraints

- Preserve charging behavior, existing history, credentials and configuration.
- No raw wire bodies, tokens, passwords, VINs or idTags in diagnostics.
- Require authentication on list/export. Parameterize SQL and bound queries, line sizes and retention.
- Diagnostics must not break a charge or a network operation if storage fails.
- Use GPT-6.1 Terra, high effort for any subagent, per user instruction.
- Leave unrelated `docs/next-patch.md` untouched.

## Review focus

- Redaction before persistence and export, including dynamic secrets and multiline input.
- Filter changes and paused/resumed polling cannot mix old/new query results or duplicate entries.
- Incremental cursors and retention gaps cannot silently skip matching entries.
- Communications that fail before a response produce useful errors without secrets.
- Mobile console, popover and toolbar remain within viewport and all controls usable by touch.
